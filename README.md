# ამბავი · ციფრული მოსაწვევები

საიტი, სადაც კლიენტი ხედავს ჩვენს დიზაინებს და შეკვეთას აკეთებს, და თავად მოსაწვევები, რომლებსაც სტუმრები ხსნიან.
ყველაფერი სტატიკურია (HTML, CSS, JavaScript): სერვერი და ბაზა არ სჭირდება, ნებისმიერ ჰოსტინგზე მუშაობს.

## ახალი მოსაწვევი

1. დააკოპირეთ მსგავსი დიზაინის საქაღალდე `invitations/`-ში ახალი **ინგლისური** სახელით, მაგ. `wedding-giorgi-ana`
   (ქართული სახელი ინტერნეტის მისამართში პრობლემას ქმნის).
2. შეცვალეთ `js/config.js`: სახელები, თარიღი, ადგილები, WhatsApp ნომერი.
3. კლიენტს გაუგზავნეთ ბმული: `<საიტი>/invitations/wedding-giorgi-ana/`

> მოსაწვევების „დედანი“ ინახება `Procect wedding\მოსაწვევები\`-ში.
> იქ ცვლილების შემდეგ გაუშვით `build-site.ps1` და `invitations/` და `assets/core|3d` აქ განახლდება.
> საიტის გვერდებს (`*.html`, `assets/site/`) სკრიპტი არ ეხება.

## ნახვა და ატვირთვა

- **კომპიუტერზე:** გახსენით `index.html`. 3D დიზაინებს ინტერნეტი სჭირდება (Three.js და შრიფტები ინტერნეტიდან იტვირთება).
- **Netlify (უფასოდ):** app.netlify.com/drop → ჩააგდეთ ეს საქაღალდე.
- **GitHub Pages:** ატვირთეთ GitHub-ზე → Settings → Pages → Branch: `main` → Save.

## გამოყენებული ტექნოლოგიები

- **HTML / CSS / JavaScript** — ჩარჩოს (framework) გარეშე, ბიბლიოთეკების ინსტალაცია არ სჭირდება
- **Three.js 0.160** — 3D სცენები (იტვირთება cdn.jsdelivr.net-დან)
- **Web Audio API** — მუსიკა ბრაუზერში იკვრება
- **Google Fonts** — Noto Serif / Sans Georgian, Cormorant Garamond, Pinyon Script და სხვ.
- **PowerShell** — `build-site.ps1`, მოსაწვევების საიტზე გადატანისთვის
